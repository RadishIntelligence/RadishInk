# 11 月 23 日提交回顾与首个正式版

本日把一篇带图文章从编辑器带到真实公众号草稿，解决了站点图标阻断 ZIP 导出、外链地址在阅读端难以获取两个问题。图片从文件拖到正文指定位置也已进入验收站。首个正式版的产品标识为 `v26.11.2-release`。

## 正式版范围与验证

- 本地 `mise exec -- pnpm validate:web` 通过，含治理 139 项、core 64 项、Web 808 项及生产构建。Web Lint 有 12 条既有警告。`mise exec -- pnpm validate:server` 通过，含服务端构建和 116 项测试。
- 站点 PNG 的首次粘贴、独立公式和手动保存有桌面实测。带 `asset/` 图片的文章仍会在复制前提示导出文章包并手工插图。手机长按复制、草稿重开及本地图片转存留待单独验证。
- 发版使用主线合并提交。下载与核验以正式 Release 的 `release-pair.json` 和两个平台锁文件为准。自托管回退使用已验证版本对应架构的部署锁及匹配的工作区备份。[正式版交付入口](https://github.com/laugh0608/RadishInk/releases/tag/v26.11.2-release) · [固定版本维护](../deployment/release-compose.md)
